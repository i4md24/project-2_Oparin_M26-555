# Primitive DB (primitive_db)

Консольный эмулятор реляционной базы данных: управление таблицами,
CRUD-операции, валидация типов, декораторы (обработка ошибок, подтверждение
опасных операций, замер времени) и кэширование результатов select на замыкании.

## Установка

Требуется uv версии 0.5+:

- uv sync — установка пакета и зависимостей в .venv;
- либо из собранного дистрибутива: uv build, затем uv tool install dist/*.whl.

## Управление таблицами

Запустите команду database (или project) — откроется интерактивный режим
работы с таблицами. Метаданные таблиц хранятся в файле db_meta.json
в текущей директории.

### Создание таблицы

    create_table <имя_таблицы> <столбец:тип> ...

Типы столбцов: int, str, bool. Первичный ключ ID:int добавляется
автоматически.

    Введите команду: create_table users name:str age:int is_active:bool
    Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

### Список таблиц

    Введите команду: list_tables
    - users

### Удаление таблицы

    Введите команду: drop_table users
    Таблица "users" успешно удалена.

При попытке удалить несуществующую таблицу:

    Ошибка: Таблица "products" не существует.

## Работа с данными

Данные таблиц хранятся в файлах data/<имя_таблицы>.json в текущей директории.
Первичный ключ ID:int генерируется автоматически: максимум существующих
значений плюс один. Условие where сравнивает значение столбца с указанным,
приводя его к типу столбца.

### Добавление строки

    insert into <имя_таблицы> values (<значение>, ...)

Значения перечисляются через запятую в порядке столбцов, столбец ID
указывать не нужно. Кавычки не используются: 25, true, Anna.

    Введите команду: insert into users values (Anna, 25, true)
    Строка с ID = 1 успешно добавлена в таблицу "users".

При неверном значении или числе значений:

    Ошибка: значение "двадцать" для столбца "age" не приводится к типу int.
    Ошибка: неверное число значений для таблицы "users": ожидалось 3, получено 1.

### Просмотр строк

    select from <имя_таблицы> [where <столбец> = <значение>]

Без условия выводятся все строки таблицы, с условием — только подходящие:

    Введите команду: select from users
    +----+-------+-----+-----------+
    | ID |  name | age | is_active |
    +----+-------+-----+-----------+
    | 1  |  Anna |  25 |    True   |
    | 2  | Boris |  30 |   False   |
    +----+-------+-----+-----------+

    Введите команду: select from users where is_active = false
    +----+-------+-----+-----------+
    | ID |  name | age | is_active |
    +----+-------+-----+-----------+
    | 2  | Boris |  30 |   False   |
    +----+-------+-----+-----------+

### Изменение строк

    update <таблица> set <столбец> = <значение> where <столбец> = <значение>

Изменяются все строки, подходящие под условие; в отчёт выводится их число:

    Введите команду: update users set age = 26 where name = "Anna"
    Обновлено строк: 1.

Если ни одна строка не подошла:

    Подходящих строк не найдено.

Столбец ID изменять нельзя:

    Ошибка: Столбец "ID" изменять нельзя, он генерируется сам.

### Удаление строк

    delete from <имя_таблицы> where <столбец> = <значение>

    Введите команду: delete from users where ID = 2
    Удалено строк: 1.

При работе с несуществующей таблицей:

    Ошибка: Таблица "products" не существует.
